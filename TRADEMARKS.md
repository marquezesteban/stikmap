# Política de marca de StikMap

La licencia GNU AGPL v3 del código fuente no concede derechos para usar el nombre, el logotipo ni la identidad visual de StikMap de una manera que sugiera respaldo u oficialidad.

## Usos permitidos

- Referirse al proyecto original como StikMap.
- Indicar de forma veraz que otro proyecto está basado en StikMap.
- Usar el nombre para explicar compatibilidad, integración o procedencia.
- Redistribuir una copia sin modificaciones conservando sus avisos y licencia.

## Versiones modificadas

Una versión modificada debe usar un nombre y una identidad visual diferentes. Puede describirse como “basada en StikMap”, siempre que quede claro que no es una versión oficial ni está respaldada por el proyecto StikMap.

No se permite usar el nombre o la identidad visual de StikMap para confundir a los usuarios sobre el origen, mantenimiento o aprobación de una versión modificada.

## Permisos adicionales

Para solicitar un uso de marca no contemplado aquí, abrir un issue en el repositorio oficial antes de publicar o distribuir el producto.

Esta política se refiere solamente a la marca. Los permisos sobre el código se rigen por el archivo `LICENSE`.
